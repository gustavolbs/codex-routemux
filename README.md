# codex-routemux

RouteMux <-> ChatGPT/Codex Desktop integration scripts.

- `sync-routemux.sh` — refresh the merged model picker (hybrid provider).
- `routemux-subagents.sh` — native subagent compatibility patch for routed models.
- `codex-storage-check.sh` — post-change checks for `~/.codex` storage.
- `CODEX_STORAGE_GUARDRAILS.md` — read before touching `~/.codex` or the provider config.
- `CODEX_HANDOFF.md` — routing/subagent context and constraints.
